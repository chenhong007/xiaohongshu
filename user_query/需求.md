## cookie管理
用户添加cookie后（首次添加cookie），需要统计cookie在线运行时长（不是添加cookie时长）；失效后要显示上次的运行时长；每次登录的时候，都需要显示开始时间，已经运行数据在前端；前后端要有cookie的加密传输；打开网站有限使用最近历史cookie，cookie如果失效要传递给前端显示

## API 限流管理
在 XHS_Apis 层面添加全局请求速率限制，统一管理 API 调用频率，避免触发小红书的反爬机制：
- 使用令牌桶算法实现平滑限流
- 全局单例模式，所有模块共享同一限流器
- 动态速率调整：检测到限流响应后自动降速
- 连续成功请求后逐步恢复速率
- 支持突发请求（burst），但长期保持平均速率
- 默认配置：每2秒1个请求，允许3个突发请求
